# Live feed smoke probe

`npm run smoke:live-feed` runs a read-only Electron main-process probe against the same Sofascore API host, `net.fetch` transport, `Accept` header, and `Referer` header as the application. It samples up to three currently live first-half, second-half, or extra-time matches and requests event, statistics, odds, and incidents once.

The JSON report includes request start, response-header time, JSON parse completion, candidate provider timestamp/age, network/parse/total latency, event/score/period validation, available xG/shots/SOT/corners/big-chance/card fields, incident response validation/count, odds parser/freshness status, parser outcome counters, and compact market-family shape summaries (line, outcome, timestamp, and provider-identity field availability). An empty statistics body is not counted as validated statistics. It does not save raw match responses or alter application settings. It uses an isolated temporary Electron user-data directory.

The probe is opt-in and is not part of `npm test`, because it depends on an external service and only works while supported live matches are available. `SKIPPED_NO_ACTIVE_MATCH` means no live fixture was available. `LIVE_FEED_VALIDATED_ODDS_UNVERIFIED_OR_STALE` means supported market shapes were parsed but their quotes lacked an admissible provider timestamp or exceeded the freshness window; parser success does not make those prices usable. One run measures a point-in-time request; it cannot measure provider-side event delay, polling freshness over time, market coverage across a season, or model accuracy. Repeat at different match states and retain reports outside the repository for latency comparisons. No bets are placed.
